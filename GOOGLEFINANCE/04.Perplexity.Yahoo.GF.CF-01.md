# Q02

I need to do is to make the following formula work 
`=AVERAGE(INDEX(GOOGLEFINANCE(E291,"close", TODAY()-200, TODAY(), "DAILY"), 0, 2))`

when `E291` holds the ticker `EXSA:ETR` or any ticker that does not have data on 
[https://www.google.com/finance/beta](https://www.google.com/finance/beta). 

This formula calculates the simple moving average of the closing price of the ETF. 

I want to be able to do the same in a Google Sheet, also for those ETF that are 
not on [https://www.google.com/finance/beta](https://www.google.com/finance/beta).

# ANSWER 02

Yes, but you must replace `GOOGLEFINANCE` with a data source that provides 
**historical daily prices**. 

`CACHEFINANCE` is not sufficient for this formula: 

it mainly supplements individual attributes such as current `price`, `name`, 
and `yieldpct`; it does not provide a historical date/close table that can be 
averaged over 200 days. 

[github](https://github.com/demmings/cachefinance)

The cleanest solution is an Apps Script custom function that retrieves 
`Yahoo Finance historical` data for the corresponding Yahoo symbol—for example, 
`EXSA:ETR` → `EXSA.DE` — and returns the 200-day average directly.

## Recommended formula

After installing the script below, use:

```gs
=YAHOO_SMA(E291,200)
```

If `E291` contains:

```text
EXSA:ETR
```

the function converts it to:

```text
EXSA.DE
```

and calculates the average of the available daily closing prices.

You can also use:

```gs
=YAHOO_SMA(E291,200,TODAY())
```

The third argument is optional and is useful when you want a fixed evaluation date.

## Apps Script implementation

In Google Sheets, open **Extensions → Apps Script**, replace the default code, and paste this:

```javascript
/**
 * Calculates the simple moving average of daily closing prices.
 *
 * Examples:
 *   =YAHOO_SMA("EXSA:ETR", 200)
 *   =YAHOO_SMA(E291, 200)
 *   =YAHOO_SMA("EXSA.DE", 200, TODAY())
 *
 * @param {string} symbol Google-style symbol, e.g. EXSA:ETR
 * @param {number} periods Number of trading-day observations
 * @param {Date} asOf Optional end date
 * @return {number}
 * @customfunction
 */
function YAHOO_SMA(symbol, periods, asOf) {
  if (!symbol) {
    throw new Error("Missing symbol.");
  }

  periods = Number(periods || 200);

  if (!Number.isInteger(periods) || periods < 1) {
    throw new Error("Periods must be a positive integer.");
  }

  const yahooSymbol = toYahooSymbol_(String(symbol).trim());

  const endDate = asOf instanceof Date && !isNaN(asOf)
    ? new Date(asOf)
    : new Date();

  endDate.setHours(23, 59, 59, 999);

  // Request substantially more calendar days than trading days.
  const startDate = new Date(endDate);
  startDate.setDate(startDate.getDate() - Math.ceil(periods * 1.7 + 30));

  const period1 = Math.floor(startDate.getTime() / 1000);
  const period2 = Math.floor(endDate.getTime() / 1000);

  const url =
    "https://query1.finance.yahoo.com/v8/finance/chart/" +
    encodeURIComponent(yahooSymbol) +
    "?period1=" + period1 +
    "&period2=" + period2 +
    "&interval=1d&events=history&includeAdjustedClose=true";

  const response = UrlFetchApp.fetch(url, {
    muteHttpExceptions: true,
    headers: {
      "User-Agent": "Mozilla/5.0"
    }
  });

  const status = response.getResponseCode();

  if (status !== 200) {
    throw new Error(
      "Yahoo Finance returned HTTP " + status + " for " + yahooSymbol
    );
  }

  const payload = JSON.parse(response.getContentText());

  if (
    !payload.chart ||
    !payload.chart.result ||
    !payload.chart.result.length
  ) {
    const description =
      payload.chart && payload.chart.error
        ? payload.chart.error.description
        : "No historical data returned.";

    throw new Error(yahooSymbol + ": " + description);
  }

  const result = payload.chart.result[0];
  const timestamps = result.timestamp || [];
  const quote = result.indicators.quote[0];
  const closes = quote.close || [];

  const prices = [];

  for (let i = 0; i < closes.length; i++) {
    const close = Number(closes[i]);

    if (Number.isFinite(close)) {
      prices.push(close);
    }
  }

  if (prices.length === 0) {
    throw new Error("No valid closing prices returned for " + yahooSymbol);
  }

  if (prices.length < periods) {
    throw new Error(
      "Only " + prices.length +
      " daily prices were returned for " + yahooSymbol +
      "; " + periods + " required."
    );
  }

  const recentPrices = prices.slice(-periods);

  return recentPrices.reduce(function(sum, value) {
    return sum + value;
  }, 0) / recentPrices.length;
}


/**
 * Converts common Google-style exchange:ticker symbols to Yahoo symbols.
 *
 * Examples:
 *   EXSA:ETR -> EXSA.DE
 *   ETR:EXSA -> EXSA.DE
 *   LON:VWRL -> VWRL.L
 *   NASDAQ:MSFT -> MSFT
 *   NYSEARCA:SPY -> SPY
 *   EXSA.DE -> EXSA.DE
 */
function toYahooSymbol_(symbol) {
  const upper = symbol.toUpperCase();

  if (upper.indexOf(".") >= 0 && upper.indexOf(":") < 0) {
    return upper;
  }

  const parts = upper.split(":");

  if (parts.length === 1) {
    return parts[0];
  }

  const first = parts[0];
  const second = parts [github](https://github.com/demmings/cachefinance);

  const exchangeMap = {
    "ETR": ".DE",
    "FRA": ".DE",
    "GER": ".DE",
    "MIL": ".MI",
    "BIT": ".MI",
    "LON": ".L",
    "LSE": ".L",
    "AMS": ".AS",
    "EPA": ".PA",
    "PAR": ".PA",
    "SWX": ".SW",
    "TSE": ".TO",
    "TSX": ".TO",
    "ASX": ".AX",
    "HKG": ".HK",
    "TYO": ".T",
    "NASDAQ": "",
    "NYSE": "",
    "NYSEARCA": "",
    "AMEX": ""
  };

  // Google symbols are normally EXCHANGE:TICKER.
  if (exchangeMap.hasOwnProperty(first)) {
    return second + exchangeMap[first];
  }

  // Also support TICKER:EXCHANGE, such as EXSA:ETR.
  if (exchangeMap.hasOwnProperty(second)) {
    return first + exchangeMap[second];
  }

  throw new Error(
    "Unknown exchange in symbol " + symbol +
    ". Use a Yahoo symbol such as EXSA.DE."
  );
}
```

The function uses Yahoo Finance’s chart endpoint, which provides OHLCV historical data and daily intervals for symbols supported by Yahoo Finance. Yahoo’s public interface is not an official guaranteed API, so it can change or impose access limits; it should not be treated as a fully contractual market-data service. [quantvps](https://www.quantvps.com/blog/yahoo-finance-api-documentation)

## Important detail: `EXSA:ETR` versus `ETR:EXSA`

Google Finance normally documents the ticker format as:

```text
EXCHANGE:TICKER
```

Therefore, the conventional Google symbol would be:

```text
ETR:EXSA
```

Your cell contains:

```text
EXSA:ETR
```

The script supports both forms, so your existing sheet does not need to be changed. For clarity, however, I recommend storing provider symbols explicitly:

| Provider | Symbol |
|---|---|
| Google-style | `ETR:EXSA` |
| Yahoo Finance | `EXSA.DE` |
| ISIN | `DE0002635307` |

The ISIN alone is not enough for the Yahoo endpoint: Yahoo requires a provider-specific ticker.

## Formula equivalent to your original

Your current formula is:

```gs
=AVERAGE(INDEX(GOOGLEFINANCE(E291,"close",TODAY()-200,TODAY(),"DAILY"),0,2))
```

The direct replacement is:

```gs
=YAHOO_SMA(E291,200)
```

If you want a version that returns blank instead of an error:

```gs
=IFERROR(YAHOO_SMA(E291,200),"")
```

If you want to calculate the SMA from a configurable number of periods stored in `F291`:

```gs
=YAHOO_SMA(E291,F291)
```

## Adjusted or unadjusted close

The script currently averages the ordinary `close` field. That is the closest equivalent to your original `GOOGLEFINANCE(...,"close",...)` formula.

For ETFs, you may instead want Yahoo’s **adjusted close**, which accounts for distributions. That produces a different moving average and is more appropriate for total-return analysis, but not necessarily for comparing the SMA with the quoted market price.

To use adjusted closes, replace:

```javascript
const quote = result.indicators.quote[0];
const closes = quote.close || [];
```

with:

```javascript
const quote = result.indicators.quote[0];
const adjusted = result.indicators.adjclose &&
                 result.indicators.adjclose[0];

const closes = adjusted && adjusted.adjclose
  ? adjusted.adjclose
  : (quote.close || []);
```

For a trading signal based on the actual ETF price, keep the unadjusted `close`. For a long-term performance analysis, consider adjusted close.

## Why CacheFinance is not the right layer

`CACHEFINANCE` is useful for formulas such as:

```gs
=CACHEFINANCE("ETR:EXSA","price")
```

when you need a current price and Google Finance fails. Its documented fallback attributes are primarily `price`, `name`, and `yieldpct`; it caches values and may query third-party sources when `GOOGLEFINANCE` returns `#N/A`. [github](https://github.com/demmings/cachefinance)

Your calculation requires a time series:

```text
date 1 → close 1
date 2 → close 2
...
date 200 → close 200
```

Consequently, you need either:

- a custom function that retrieves historical data, as above;
- a financial-data API with historical prices;
- a scheduled Apps Script that writes daily prices into a sheet.

Using a current-price fallback 200 times would be slower, less reliable, and conceptually incorrect.

## Reliability considerations

Custom functions can be recalculated unexpectedly, and repeatedly calling an external endpoint for many ETFs may trigger rate limits. For a small number of ETFs, `YAHOO_SMA` is usually convenient. For a larger portfolio, a better architecture is to retrieve the daily prices once per day into a sheet and calculate the SMA locally:

```gs
=AVERAGE(FILTER(B2:B1000,A2:A1000>=TODAY()-200))
```

This avoids making one external request every time the spreadsheet recalculates.

Also note that your original formula uses `TODAY()-200`, which represents approximately 200 calendar days, not 200 trading sessions. The script explicitly returns the last 200 available trading-day closes. That is normally what “200-day SMA” means.

# ANSWER 01

Yes—but not by changing `GOOGLEFINANCE` itself. 

Google Sheets can query only the securities and attributes available 
in Google Finance’s underlying data feed; it cannot import an ETF 
merely because Google Finance’s website can identify its ISIN. 

Google explicitly notes that some attributes do not work for all 
symbols and that it does not support most international exchanges. 

[support.google](https://support.google.com/docs/answer/3093281)

For this ETF, the issue is probably the **Xetra/ETR quote feed**, 
not the ISIN mapping. `DE0002635307` is correctly associated with 
ticker `EXSA`, and the Xetra listing is also shown as `EXSA` by BlackRock.  

Yahoo Finance, meanwhile, exposes the quote as `EXSA.DE` and currently 
provides delayed Xetra data. 

[blackrock](https://www.blackrock.com/lu/intermediaries/products/251931/ishares-stoxx-europe-600-ucits-etf-de-fund)

## What to try first

Use the exchange-qualified ticker rather than the ISIN:

```gs
=GOOGLEFINANCE("ETR:EXSA","price")
```

You can also test:

```gs
=GOOGLEFINANCE("ETR:EXSA","currency")
=GOOGLEFINANCE("ETR:EXSA","closeyest")
=GOOGLEFINANCE("ETR:EXSA","volume")
```

However, if these return `#N/A`, there is no formula syntax that 
will force Google to retrieve the data. The following alternatives 
are worth testing, but they are not equivalent listings and should 
not be silently substituted in a portfolio:

```gs
=GOOGLEFINANCE("FRA:EXSA","price")
=GOOGLEFINANCE("EXSA","price")
```

`FRA:EXSA` refers to a Frankfurt listing, while `ETR:EXSA` refers to Xetra. 
They may have different liquidity, trading hours, prices, or availability. 
Google recommends specifying both the exchange and ticker to avoid discrepancies. 

[support.google](https://support.google.com/docs/answer/3093281)

## Using Yahoo Finance as the fallback

Yahoo’s symbol is:

```text
EXSA.DE
```

You can sometimes retrieve the current value in Google Sheets with:

```gs
=IMPORTDATA("https://query1.finance.yahoo.com/v8/finance/chart/EXSA.DE?range=1d&interval=1m")
```

But this is not a convenient or stable solution: Yahoo’s response is JSON, 
`IMPORTDATA` may not parse it usefully, and Yahoo can change or restrict 
undocumented endpoints. A better approach is an `Apps Script` function using `UrlFetchApp`, preferably against an official or licensed API.

For example, if an API returns JSON in the form:

```json
{
  "price": 66.04,
  "currency": "EUR",
  "timestamp": "2026-08-19T13:34:01+02:00"
}
```

you could expose a custom Sheets function such as:

```javascript
function YAHOOFINANCE(symbol, attribute) {
  const url =
    'https://query1.finance.yahoo.com/v8/finance/chart/' +
    encodeURIComponent(symbol) +
    '?range=1d&interval=1m';

  const response = UrlFetchApp.fetch(url, {
    muteHttpExceptions: true,
    headers: { 'User-Agent': 'Mozilla/5.0' }
  });

  if (response.getResponseCode() !== 200) {
    throw new Error('Yahoo Finance returned HTTP ' + response.getResponseCode());
  }

  const data = JSON.parse(response.getContentText());
  const result = data.chart.result && data.chart.result[0];

  if (!result || !result.meta) {
    throw new Error('No quote data returned for ' + symbol);
  }

  const meta = result.meta;

  switch (String(attribute).toLowerCase()) {
    case 'price':
      return meta.regularMarketPrice ?? meta.previousClose;
    case 'currency':
      return meta.currency || '';
    case 'previousclose':
      return meta.previousClose ?? '';
    default:
      throw new Error('Unsupported attribute: ' + attribute);
  }
}
```

Then:

```gs
=YAHOOFINANCE("EXSA.DE","price")
```

This should be treated as an example rather than production-grade infrastructure. 
For a reliable portfolio tracker, use a provider with a documented API, 
authentication, rate limits, and terms that permit your intended use.

## Does CacheFinance solve it?

`cachefinance` may help, but it does not extend Google Finance’s database. 
It works as a custom Apps Script function that:

1. Tries `GOOGLEFINANCE`.
2. Uses a cached previous value when Google returns `#N/A`.
3. Attempts third-party websites or APIs for selected attributes such as `price`, `name`, and `yieldpct`.

The project specifically describes unsupported-symbol fallback lookups 
and cached values, but it also warns that third-party lookups can be slow, 
may fail, and may return `0` or an empty value if no source works. 

[github](https://github.com/demmings/cachefinance)

For your ETF, the first test would be:

```gs
=CACHEFINANCE("ETR:EXSA","price")
```

If the library’s Yahoo fallback understands the `ETR:EXSA` format, 
it may convert it to the Yahoo symbol `EXSA.DE`. If it does not, 
try the Yahoo-style symbol:

```gs
=CACHEFINANCE("EXSA.DE","price")
```

Whether that works depends on the version of the script and its source-selection logic. The repository is relatively old—the latest listed release is from November 2022—so I would inspect and test its current Yahoo adapter before relying on it for financial records. 

[github](https://github.com/demmings/cachefinance)

You can also provide a default Google value when Google works intermittently:

```gs
=CACHEFINANCE(
  "ETR:EXSA",
  "price",
  GOOGLEFINANCE("ETR:EXSA","price")
)
```

For an always-unsupported symbol, however, the default itself evaluates to `#N/A`; therefore the third-party lookup must support that symbol format.

## Recommended design

For a portfolio spreadsheet, I would separate **security identity**, **data provider**, and **provider symbol**:

| Security | Exchange | Google symbol | Yahoo symbol |
|---|---|---|---|
| ISIN `DE0002635307` | Xetra | `ETR:EXSA` | `EXSA.DE` |

Then use a fallback formula:

```gs
=IFERROR(
  GOOGLEFINANCE(B2,"price"),
  YAHOOFINANCE(C2,"price")
)
```

Where:

- `B2` contains `ETR:EXSA`.
- `C2` contains `EXSA.DE`.

For a simple personal sheet, `CACHEFINANCE` is worth trying because it gives you caching and fallback behavior with little implementation effort. For a more dependable solution, 
I would use a small Apps Script wrapper around a documented market-data API and store the provider-specific symbol separately from the ISIN.

Do not use cached values for current valuation without also storing the timestamp and source. A cached price can be useful for avoiding gaps in charts, but it should not be mistaken for a current market quote.
